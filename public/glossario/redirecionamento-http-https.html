Redirecionamento de HTTP para HTTPS

Configuração da porta 80 para encaminhar quem acessa por http:// para a versão https:// do mesmo endereço.

Por que importa

É o que protege quem digita o endereço sem o "https". Servir conteúdo na porta 80 sem redirecionar permite leitura e alteração na rede. O redirecionamento deve ser permanente (301 ou 308) e ficar no mesmo domínio.

Como o Verifica verifica

O que a porta 80 responde: redirecionamento para HTTPS do mesmo domínio, redirecionamento para HTTP, outro domínio ou conteúdo sem redirecionar.

Como corrigir

return 301 https://$host$request_uri;   # nginx

Depois de funcionar, ative o HSTS.
